# Quick Start 🚀

1. サーバーに[BOT](https://discord.com/oauth2/authorize?client_id=1342526334529835048&permissions=280576&integration_type=0&scope=bot)を招待
2. サーバーまたはBOTのDMで`/register`コマンドを使用する（通知先チャンネルを省略するとコマンドを実行したチャンネルに通知）
3. 登録を解除する場合は`/unregister`コマンドから対象を選択する

# 通知の難易度表示

数値DifficultyとNoviStepsの級段を併記し、級段から問題の投票ページへ移動できます。未確定の級段には「暫定」と表示します。両方の情報がない場合は「難易度: 不明」と表示します。

通知の色は数値Difficulty、NoviSteps級段、典型90の公式★の順に決めます。級段の色はbot独自の目安で、数値Difficultyへの換算ではありません。言語情報は提出日時とともにフッターへ表示します。

新しいRatedのアルゴリズム問題に数値Difficultyがまだない場合は、「diff: 未確定」で先に通知します。コンテスト終了から72時間まで毎分確認し、公開されたら元の通知のDiffと色を更新します。期限までに公開されなかった場合は「diff: 不明」に更新して監視を終了します。NoviStepsの表示は通知時の内容を維持します。監視状態は`bot.db`に保存するため再起動後も継続します。

Diffモデルもコンテスト情報も未掲載の場合は従来どおり通知を保留し、提出時刻から72時間を仮期限に再確認します。AtCoderへの認証、順位表からの暫定Diff計算、公式ページからのコンテスト情報の補完は行いません。

NoviStepsのデータは全利用者で共有し、24時間に1回取得します。取得したデータはGit管理外の`bot.db`に保存し、更新に失敗した場合は前回分を利用します。取得済みの一覧・キャッシュはGitに追加しないでください。テストには架空のデータを使っています。

# Manual Setup (Self hosted)
1. ルートディレクトリに`config.ini`を作成
```ini
[DISCORD]
TOKEN = ここにBOTのトークンを記載
```
2. main.pyを起動
 （適宜`pip install discord`などで足りないモジュールをインストール）
